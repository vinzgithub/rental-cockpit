# Security and data protection

## Accounts and sessions

- **No default account.** The first visit creates the administrator; the creation page is refused afterwards.
- **Passwords**: at least 10 characters, hashed with scrypt (N = 2¹⁴, r = 8, p = 1). An unknown user name takes as long as a wrong password.
- **Throttling**: after five failures from one address, attempts are refused for five minutes. The message never says whether the user name exists.
- **Session**: signed cookie, `HttpOnly`, `SameSite=Strict`, `Secure` when `RENTAL_COCKPIT_COOKIE_SECURE=true`. The signing key is created on first start in the data folder (mode 0600). Changing the password, or turning two-factor sign-in on or off, signs out the account's other browsers.
- **Two-factor sign-in** (optional, recommended): in **Settings**, after confirming the password, a QR code generated by the server is added to an authenticator app; a first valid code turns it on. TOTP codes (RFC 6238: SHA-1, 6 digits, 30 s) with one step of tolerance; each code is accepted once. Ten single-use recovery codes are shown once and kept only as SHA-256 hashes. Turning it off or renewing the codes requires the password and a code. At sign-in, the right password opens nothing: the code is asked within five minutes. The TOTP secret has to stay readable to check codes: it is stored in the database, so protect the `/data` folder and its backups.
- **Lost phone** and no recovery code left: only someone with access to the server can turn two-factor sign-in off (`python -m rental_cockpit.cli disable-mfa <username>`, see [installation.md](installation.md)).

## Rights

| Profile | Can |
|---|---|
| Administrator | Configure, record, import, correct, back up and restore |
| Reader | View only the granted properties; open PDFs only when explicitly granted |
| Not signed in | Nothing but the sign-in page |

Rights are checked **on the server** for every request. Hiding a button is never a protection. Totals only cover permitted properties: a hidden property appears in no list and no sum. A guessed property identifier is refused.

The demo (fictional data) can be viewed by any signed-in account and changed by administrators only.

## Requests

- **Anti-CSRF token** required on every change.
- **Idempotent operations**: each action carries a unique identifier; a double click or a network retry is saved once.
- **All or nothing**: a change is applied to a copy, written in one SQLite transaction, then published. On failure the previous state is kept and the message says so.
- **No silent overwrite**: each stay carries a revision number; a change made on an outdated version (somebody else saved in between) is refused and the message asks to reload.
- **Text**: everything typed or imported is handled as text, never as HTML.

## File imports

- **Administrators only**; CSRF token required, like any change.
- **5 MiB and 20,000 lines at most.** A workbook (.xlsx, .ods), a PDF or any binary file is refused with a clear message. Accepted encodings: UTF-8, or Windows-1252 stated in the preview.
- **The file is not kept**: it is read in memory for the preview and again for the confirmation; only its SHA-256 fingerprint is kept, to flag a file already imported.
- **Nothing is written during the preview.** On confirmation the import is computed again on the current data: if it no longer matches the preview shown (someone changed the stays in the meantime), it is refused and the new preview is shown.
- **Guests' names are not kept** by default: only the reference, dates and amounts are saved, unless chosen explicitly.
- **One import, one journal line** (author, date, number of stays and payouts), so older journal entries are not pushed out.
- **Undo** of the last import only, and only if none of its stays was changed since: nothing entered afterwards is erased.

## CSV exports

- The exports of the expenses and the stays only contain the properties the account can see, with the filters shown on screen. A reader can export their properties; they cannot change anything.
- **Formulas neutralised**: a text that would start with `=`, `+`, `-`, `@`, a tab or a carriage return is written with a leading apostrophe. A label typed or imported can never become a formula in an accountant's spreadsheet. Amounts are produced by the application and written as plain numbers.
- The file is neither kept on the server nor cached (`Cache-Control: no-store`).

## Suppliers

- Suppliers are shared by every property. A reader sees them with totals (invoices, left to pay, left to split) computed **on their own properties only**: the invoices of a property they were not granted appear in no total.
- Creating, editing or archiving a supplier, breaking down, splitting or reconciling an invoice: administrators only, with the usual CSRF token, revision number and operation identifier.
- A reconciliation is fully checked before anything is written (same property, amounts, payments): when it is refused, nothing has changed.

## Browser

- Strict Content-Security-Policy: `default-src 'self'`, no inline or external script or style, no framing by default (`frame-ancestors 'none'`).
- `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, restrictive `Permissions-Policy`, API responses never cached.
- Fonts and icons are served by the application: no request to any other site.

## API keys (Home Assistant)

- **Read-only**: a key reads the `/api/v1/summary` summary with its account's rights (same properties, real data only) and can change nothing.
- Shown once, kept only as a SHA-256 hash, revocable at any time; the last read date is shown.
- Ten active keys at most per account. See [home-assistant.md](home-assistant.md).
- The app refuses to be shown in a frame, except for the origins listed in `RENTAL_COCKPIT_FRAME_ANCESTORS`.

## Data

- **Local storage only**: no telemetry, no vendor account, no outbound call.
- All data is in the `/data` folder: protect it and its backups, which hold private information. This includes `backups/`, where a full copy of the database is written before each data format migration.
- Guest data is kept to the minimum useful (a label and a number of guests). On import, their name is only taken when you ask for it.
- The operations log records author, date, action, item and result; it holds no secret and no PDF content. It is not a certified legal archive.

## Network exposure

- Use Rental Cockpit on your local network or through a VPN.
- If outside access is unavoidable: HTTPS reverse proxy, `RENTAL_COCKPIT_COOKIE_SECURE=true`, `FORWARDED_ALLOW_IPS` set to the proxy's address, and two-factor sign-in turned on. The proxy must accept 8 MiB requests for imports (the file travels encoded with its choices).
- The base installation opens no port on your router.
