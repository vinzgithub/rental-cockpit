# Justificatifs d'exemple

Fichiers fictifs pour essayer l'écran **Justificatifs** sans utiliser de vraies factures.

| Fichier | Ce qu'il montre |
|---|---|
| `facture-fictive-F-TEST-001.pdf` | Facture lisible : numéro F-TEST-001, date 20/10/2026, total TTC 45,00 €, prestataire « Ménage Essai » (proposé si ce prestataire existe) |
| `scan-fictif.pdf` | PDF sans texte, comme un scan : accepté, rien n'est proposé, tout se saisit à la main |
| `protege-par-mot-de-passe.pdf` | PDF qui demande un mot de passe pour s'ouvrir : refusé |
| `pas-un-pdf.pdf` | Fichier texte renommé en .pdf : refusé |

Envoyer deux fois le même fichier, même renommé, montre la détection des doublons.
